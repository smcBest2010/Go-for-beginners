# 초보자들을 위한 Go언어 (Go Cheat Sheet for Beginners)

Go 언어를 처음 시작하는 고등학생/초보자를 위해 가장 직관적으로 문법을 정리해 둔 저장소입니다.
누구나 쉽게 보고 따라 할 수 있게 예제 코드를 아카이빙했습니다.

## 예제 실행 방법

각 폴더로 이동한 뒤 `go run`으로 바로 실행할 수 있습니다.

```bash
cd 01-hello-world
go run main.go
```

## 사전 준비물

- [Go 설치](https://go.dev/dl/) (1.21 이상 권장)
- 코드 에디터 (VS Code + Go 확장 추천)

```bash
go version
```
